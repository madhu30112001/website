# 🏠 Nesto - Airbnb Clone

**Nesto** is a full-stack Airbnb-inspired web application where users can list, browse, and book accommodations. Built using the MERN stack with Tailwind CSS, it offers a responsive and seamless booking experience.

---

## 🚀 Tech Stack

### 🖥️ Frontend
- **React.js** – Component-based frontend library
- **Tailwind CSS** – Utility-first CSS framework for fast UI development
- **Plain CSS** – Custom styles for additional UI components

### 🌐 Backend
- **Node.js** – JavaScript runtime for the server
- **Express.js** – Web framework for building APIs

### 🗃️ Database
- **MongoDB Atlas** – Cloud-hosted NoSQL database to store users, listings, and bookings

---

## 🔧 Features

- 🔐 User registration and login
- 🧑 Profile and account management
- 🏡 Host can add & edit listings
- 📆 Users can book places with check-in/check-out
- 📷 Image uploads for listings
- 📱 Mobile-first responsive design
