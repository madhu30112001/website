# Food Website

A modern, responsive food delivery website built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js,Redux). This project delivers a seamless experience for browsing menus, placing orders, and managing accounts.

---

## 🚀 Features

- ✅ **User Authentication**: Sign up, log in, and secure user access.
- 🍽️ **Dynamic Menu**: Explore and filter real-time food categories.
- 🛒 **Order Management**: Add to cart, place orders, and track delivery.
- 💳 **Payment Integration**: Secure payment gateway integration (e.g., Paypal).
- 🛠️ **Admin Panel**: Control menu items, view user orders, and update statuses.
- 📱 **Mobile Responsive**: Optimized for both desktop and mobile devices.

---

## 🛠️ Technologies Used

### 🔹 Frontend
- React.js
- React Router
- Redux Toolkit
- Tailwind CSS / SCSS
- Axios

### 🔹 Backend
- Node.js
- Express.js
- MongoDB + Mongoose

### 🧪 Testing
- Vitest
- React Testing Library
- Jest DOM

---

## 📦 Installation & Setup

### 🔧 Prerequisites
- Node.js installed
- MongoDB server (local or cloud MongoDB Atlas)
- `npm` or `yarn`
